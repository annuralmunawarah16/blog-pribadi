# Blog Pribadi

Ini adalah proyek blog pribadi yang dibuat menggunakan HTML, CSS, dan JavaScript. Blog ini digunakan untuk berbagi cerita, pengalaman, dan berbagai topik menarik yang saya minati.

## Deskripsi

Blog pribadi ini dirancang untuk menyediakan platform bagi saya untuk menulis dan berbagi artikel secara online. Di dalam blog ini, pengunjung bisa membaca artikel tentang berbagai topik, mulai dari teknologi, gaya hidup, hingga cerita pribadi saya.

## Fitur

- Halaman utama yang menampilkan daftar artikel terbaru.
- Setiap artikel memiliki halaman terpisah dengan konten lengkap.
- Halaman tentang saya untuk memperkenalkan diri.
- Desain responsif untuk tampilan yang optimal di perangkat desktop maupun mobile.

## Cara Instalasi

1. Clone repository ini ke komputer kamu:
   bash
   git clone https://github.com/annuralmunawarah16/blog-pribadi.git
	2.	Masuk ke dalam folder proyek:
cd blog-pribadi
3.	Buka file index.html di browser untuk melihat halaman utama blog:
open index.html
Teknologi yang Digunakan
	•	HTML: Untuk struktur halaman.
	•	CSS: Untuk styling dan desain halaman.
	•	JavaScript: Untuk menambah interaktivitas di blog.
